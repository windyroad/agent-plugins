# Limit an operator export to 500 records

## Decision Outcome

Reject an operator export when its matching set exceeds 500 records.
For sets of 500 or fewer, preserve the existing complete export behavior.
This changes the previous behavior for larger, otherwise valid exports.

## Confirmation

This record remains proposed and unconfirmed. Acceptance is a later change
requiring human confirmation of the final decision and production-use evidence.
