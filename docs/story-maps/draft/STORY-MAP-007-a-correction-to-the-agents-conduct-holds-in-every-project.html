STORY-MAP-007: A correction to the agent's conduct holds in every project

A maintainer should only have to correct the agent's conduct once. Today that correction dies with the session it lands in, and it never reaches another project at all: the agent's defaults reset, so a correction held only in conversation, or in a maintainer's private notes, changes nothing for the next turn and nothing for anyone who installs the plugins. This map covers carrying those corrections as rules that ship. Its first rib carries the correction an inbound report already raised: the agent asks for a long URL through a fixed-options picker with no field to paste into. (Traces: P438, inbound #324; JTBD-011, JTBD-101.)
