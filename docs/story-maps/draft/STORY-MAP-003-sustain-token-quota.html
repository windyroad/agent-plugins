Sustain my token quota across the week and across surfaces

A user story map for the developer (JTBD-010) whose Claude Code, chat, and Cowork all draw on one shared weekly quota. Read left to right as what I get: I lean on Claude all week, my work paces itself, I stay in flow even when I'm over budget, I keep enough for my other surfaces, and it all protects me from the moment I install it — so I can set an overnight run and go to bed instead of getting hard-stopped mid-task. Each card is a value I get, in my own voice; the linked STORY / ADR is the implementer. Ratified 2026-07-08 (ADR-090); further refined at the /wr-itil:manage-story-map accepted transition.
