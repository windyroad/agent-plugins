STORY-MAP-005: Trust the capture-on-correction signal

When a user tells the agent it got something wrong, that correction should become a durable problem record rather than decaying with the session — that is the job the capture-on-correction nudge exists to do. The nudge only works if it means something. Today its prompt detector fires on any prompt containing an imperative like "do not", including the framework's own iteration prompts, so a signal that should be rare and pointed arrives on nearly every autonomous iteration with no correction behind it. This map covers making the nudge trustworthy by teaching the detector to distinguish user-authored prompts from framework-generated ones. (Traces: P430, inbound #257; JTBD-006.)
