STORY-MAP-010: Trust that a ticket states only what was verified

A problem ticket is read downstream as ground truth — by the ranking pass, by whoever writes the fix strategy, by the gate that mints a fix vehicle. So when capture transcribes whatever the reporter or the agent asserted, an untested claim gets the same authority as a confirmed finding. A report that some component is missing is never checked against the tree, and a root cause nobody executed is written in the same voice as one that was. This map covers making a ticket say only what someone actually established: test the claims that can be tested at intake, and give the ones that cannot a place to sit that is honestly labelled as a guess. (Traces: P434, inbound #202 and #339; JTBD-002; ADR-100.)
