Learnings about the external-comms gate as it applies to `git commit` **message** review (P082 surface) — how the gate derives the marker key from the command string and how repeated message flags are reconstructed. ## What You Need to Know

- **Repeated quoted `-m` and `--message` values are reconstructed in command order and joined with `\n\n`, matching Git's paragraph semantics.** P415 removed the first-match `break` in the canonical shared hook and synchronized the established risk-scorer and voice-tone copies. The focused behavioural regression pre-places the full-message marker, runs `git commit -m "subject" --message 'body' -m "trailer"`, and requires a silent permit. Extracted package checks also cover repeated flags, a single flag, and the unchanged heredoc path. The fix shipped in `@windyroad/risk-scorer@0.18.19` and `@windyroad/voice-tone@0.8.1`; installed sessions must refresh and restart before repeated flags use the new parser.
