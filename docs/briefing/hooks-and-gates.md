# Hooks and Gates

Learnings about PreToolUse/PostToolUse gate behaviour, markers, and expiry.

## What You Need to Know

- **Candidate-SID enumeration remains an ITIL create-gate tradeoff, not an oversight-authority pattern.** ADR-050, Capture the runtime stdin `session_id`, deliberately bounds `wr-itil-mark-create-gate` fanout to 1440 minutes and accepts a recoverable fail-closed denial when a long-running caller is absent. Do not widen the window or pick a newer unrelated session. Architect and JTBD oversight instead use the exact successful standalone command's `PostToolUse:Bash` session evidence, as recorded in [Hook Authoring - Shell Portability](./hook-authoring-portability.md). P502, The marker shim's 24h candidate-SID window excludes long sessions, closed after current-source and published-package verification confirmed that redesign. <!-- signal-score: 0 | last-classified: 2026-08-31 | first-written: 2026-08-31 -->
- **Read-only style-guide and voice-tone reviewers return the verdict; the PostToolUse hook must parse it and fail closed.** P469 traced the live path end to end: the old hooks ignored `tool_response`, read process-global `/tmp/*-verdict` files, and treated absence as PASS, so a FAIL could still create the gate markers. The fixed hooks accept only the first canonical PASS heading from the completed `Agent` output; VIOLATIONS FOUND, GUIDE UPDATE NEEDED, malformed, or missing output writes nothing. Never forge a reviewer verdict file. Installed caches retain the old behaviour until the patched packages are released and refreshed. **Separate P466 risk-scoring caveat:** `wr-risk-scorer:pipeline` has no Bash, so give it the staged change inventory and do not assume it can inspect the index. <!-- signal-score: 7 | last-classified: 2026-08-31 | first-written: 2026-07-26 -->

- **The risk-scorer's `RISK_CWD:` binding contract exists only in the Codex build of the agent, so the `SubagentStop` receipt path is dead on Claude Code.** `scripts/codex-agents.mjs` appends a `## Codex assessed-checkout binding` section when it generates `.codex/agents/wr-risk-scorer-pipeline.toml`; `packages/risk-scorer/agents/pipeline.md` never carries it, and its Below-Appetite Output Rule whitelists only the report, `RISK_SCORES:` and `RISK_BYPASS:`. The completion bridge requires exactly one `RISK_CWD:` line in the agent's output, so every Claude Code risk-scorer `SubagentStop` rejects with `missing-risk-cwd` — harmless while `PostToolUse:Agent` fires, but it means the receipt cannot rescue a dispatch where that hook does not fire, and it overwrites the single shared diagnostic at `$TMPDIR/claude-risk-pending/subagent-stop-diagnostic.json` that the Codex path relies on for its own failures. Read the diagnostic before assuming an event never fired. P477 / P402. (2026-08-21.) <!-- signal-score: -2 | last-classified: 2026-08-30 | first-written: 2026-08-21 -->
