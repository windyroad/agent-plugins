## What You Need to Know

- **Story ratification (ADR-090/096) has no AFK carve-out — an iter whose fix-vehicle RFC carries `stories: []` can only capture story infrastructure and hold.** Even with the fix direction substance-ratified (ADR-074 satisfied), ADR-089 requires ≥1 story, ADR-095 requires map membership at capture, and ADR-090 rule 3 + ADR-096 make ratify → accept → wire `stories:` → implement interactive-only. The AFK shape: capture the story-map + story born `human-oversight: unconfirmed` (legal — unconfirmed artefacts may exist), do NOT edit the RFC's frontmatter `stories:` array (the derived `## Stories` body table via the reverse-trace helper is fine), queue ratify→accept→wire→implement to `outstanding_questions`, report partial-progress. Witnessed P376 Gap 2 iter 2026-07-15 (took 3 architect reviews to converge); P456 tracks the friction fix. **Second witness P430 iter 2026-07-26, and it generalises: the ticket had no fix vehicle at all, so this is not specific to a pre-existing `stories: []` RFC — ANY fix-implementation iter now walks map → RFC → story → ratify and stops at ratify.** That iter's fix was a 3-line env-var guard plus one SKILL export line (effort S, approach covered by four existing ADR precedents) and it still could not land; the budget went to 3 architect + 2 style-guide + 2 voice-tone + 1 accessibility review and three new artefacts. Do not plan an AFK iter around landing code — plan it around authoring the vehicle and queueing the ratification, and say so in the summary. Also: the architect refuted the tempting shortcut of accepting the story mechanically (I7+I8+I10 pass without ratification) — ADR-095 line 45 + ADR-096 lines 19/25/44 put ADR-090 ratification AT the accepted gate, so accept-then-implement is the ADR-096 bypass class, not a loophole. That the code permits it is now P465. **Third witness P431 iter 2026-07-26 — the shape is now the default, so budget for it.** That iter's fix was a single `jq` branch in one lib helper, and reaching the hold cost 9 reviewer spawns (3 architect + 2 jtbd + 1 style-guide + 1 voice-tone + 1 accessibility + 1 risk-scorer) and four new artefacts.
