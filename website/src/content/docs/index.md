Windy Road Agent Plugins add architecture reviews, risk assessment, testing
discipline and delivery workflows to AI coding sessions. Install the plugins
relevant to your work, then configure them for your project's rules.

## Get started

[Install your first plugins](./getting-started/), then restart your coding agent.
Claude Code is the default runtime. [Read the runtime guidance](./runtimes/)
before installing for Codex.

## Explore plugins

- [Architecture](./plugins/architect/): record and review architecture decisions.
- [Risk assessment](./plugins/risk-scorer/): assess changes and pipeline actions.
- [Testing discipline](./plugins/tdd/): work through a test-first development cycle.
- [Jobs to be done](./plugins/jtbd/): check changes against the people and outcomes they serve.
- [Outcome-led planning](./plugins/planning/): confirm the outcome and iteratively deliver through Now, Next and Later.
- [Service management](./plugins/itil/): manage problems and incidents.
- [Retrospectives](./plugins/retrospective/): retain learning from coding sessions.
- [Voice and tone](./plugins/voice-tone/) and [style guidance](./plugins/style-guide/): follow project conventions.
- [Cruise](./plugins/cruise/): pace coding-agent usage across rate-limit windows.
- [C4 diagrams](./plugins/c4/) and [Wardley maps](./plugins/wardley/): explore architecture and capabilities.
- [Connect](./plugins/connect/): collaborate across coding sessions through Discord.

Each plugin page lists its skills, source version and recorded maturity. These
are repository reference pages; verify your installed version when behavior
differs. Plugin maturity and runtime coverage vary.

## Find a skill

Use search for a task or skill name, or expand Skills in the navigation.
[Outcome-led planning](./outcome-led-planning/) helps establish a confirmed
objective and deliver toward it through Now, Next and Later increments.

## Keep your installation current

[Update or remove plugins](./updating/) without editing their installed cache.
Source code and full skill instructions are available in the
[public repository](https://github.com/windyroad/agent-plugins).
