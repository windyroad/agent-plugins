Published prose states the rule instead of citing an internal identifier

The Connect README and the Cruise quota-pace throttle hook each carried a
decision or problem number from the Windy Road source repository. Those corpora
are not part of any package, so the number resolved to nothing in an installed
tree — or worse, to a same-numbered document in the adopter's own governance
folder. Each reference is now replaced by the substance it stood for, or dropped
where the surrounding sentence already said it. Two Connect README links that
pointed outside the package have gone with them.

Behaviour is unchanged. This is the next bounded step in migrating every package
to self-contained published instructions, and a repository check now keeps the
already-migrated packages that way.
